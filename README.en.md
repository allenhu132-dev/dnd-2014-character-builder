# D&D 2014 Character Builder

[简体中文](README.md)

Create a character, compare subclasses, and plan levels 1–20 using the 2014 rules for D&D 5th Edition. The builder has a Chinese interface and opens with an editable level 1 human fighter. You can also start with a blank character. No account is required.

**[Open the character builder](https://allenhu132-dev.github.io/dnd-2014-character-builder/)**

## Create your first character

1. Explore the sample character or select **从空白建卡** (Start from scratch). The home screen has sections for race, class, ability scores, background, equipment, spells, and leveling. Select an item under **建卡检查** (Build checklist) to jump to the relevant choices.
2. Click an option to preview it, then choose **选择此项** (Select this option) to apply it. Use **子职对照** (Compare subclasses) to view two subclasses side by side, with features aligned by level.
3. Open **升级** (Leveling) to preview future levels and see what choices unlock. Select **设为实际等级** (Set as actual level) when you're ready to apply the level.

## Use it offline

Open **角色管理** (Character management) and select **下载离线工具** (Download offline tool). Save `DND-2014-Character-Builder.html` and open it in your browser. You can send that HTML file directly to friends.

If the site is unavailable, download the [offline file from GitHub](https://raw.githubusercontent.com/allenhu132-dev/dnd-2014-character-builder/main/DND-2014-Character-Builder.txt), change the extension from `.txt` to `.html`, and open it in your browser.

## Save and share characters

- Characters save automatically in your current browser. The website and offline file keep separate saves.
- To switch devices or move between the website and the offline file, export a JSON save from **角色管理** (Character management), then import it on the other device or version. Full saves can include private notes.
- Use **分享角色** (Share character) to preview a public summary before sending it to your group. The summary hides race and private notes by default.

## Rules coverage

The builder supports single-class progression for all 12 classes in the 2014 *Player’s Handbook* and includes options from selected 5e supplements. Open an option’s full rules to see its requirements and limits. Some supplemental effects require manual entry or a ruling from your DM.
