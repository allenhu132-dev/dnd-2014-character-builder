# D&D 2014 Character Builder

[简体中文](README.md)

Create a character, compare subclasses, and plan levels 1–20 using the 2014 rules for D&D 5th Edition. The builder opens with an editable level 1 human fighter. You can also start with a blank character. No account is required.

**[Open the builder in English](https://allenhu132-dev.github.io/dnd-2014-character-builder/?lang=en)**

Use **Settings → Language** to switch between English and Simplified Chinese. Both languages use the same character library. The offline tool also includes both languages.

## Create your first character

1. Explore the sample character or select **Start from Scratch**. The home screen has sections for race, class, ability scores, background, equipment, spells, and leveling. Select an item under **Build Checklist** to jump to the relevant choices.
2. Click an option to preview it, then choose **Select This Option** to apply it. Use **Compare Subclasses** to view two subclasses side by side, with features aligned by level.
3. Open **Leveling** to preview future levels and see what choices unlock. Select **Set as Actual Level** when you're ready to apply the level.

## Use it offline

Open **Settings** and select **Download Offline Tool**. Save `DND-2014-Character-Builder.html` and open it in your browser. You can send that HTML file directly to friends.

If the site is unavailable, download the [offline file from GitHub](https://raw.githubusercontent.com/allenhu132-dev/dnd-2014-character-builder/main/DND-2014-Character-Builder.txt), change the extension from `.txt` to `.html`, and open it in your browser.

## Save and share characters

- Characters save automatically in your current browser. The website and offline file keep separate saves.
- To switch devices or move between the website and the offline file, export a JSON save from **Settings**, then import it on the other device or version. Full saves can include private notes.
- Use **Share Character** to preview a public summary before sending it to your group. The summary hides race and private notes by default.

## Rules coverage

The builder supports single-class progression for all 12 classes in the 2014 *Player’s Handbook* and includes options from selected 5e supplements. Open an option’s full rules to see its requirements and limits. Some supplemental effects require manual entry or a ruling from your DM.

English spell summaries and core class and subclass features use 2014 D&D terminology. Some supplemental rule details still use machine-assisted translations. See the [2014 Basic Rules](https://www.dndbeyond.com/sources/dnd/basic-rules-2014) and the sources listed on individual rule cards.
